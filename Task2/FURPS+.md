
| Код    | Требования                                                                                                                                    | Комментарий                                                                                                    |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| **F**  | **Функциональные (Functionality)**                                                                                                            |                                                                                                                |
| F1     | На сайте отображается список доступных депозитов с актуальными ставками                                                                       |                                                                                                                |
| F2     | Клиент подает через сайт заявку на депозит (номер телефона, ФИО)                                                                              |                                                                                                                |
| F3     | В системе кол-центра менеджер видит оставленные на сайте заявки                                                                               |                                                                                                                |
| F4     | Интернет-банком могут пользоваться только зарегистрированные пользователи                                                                     | Новому клиенту надо прийти в отделение для идентификации, после чего он будет зарегистрирован в интернет-банке |
| F5     | В интернет-банке клиент видит список доступных депозитов с актуальными и персонализированными ставками                                        |                                                                                                                |
| F6     | В интернет-банке клиент подает заявку на открытие депозита (счет, сумма депозита)                                                             |                                                                                                                |
| F7     | Операцию открытия депозита в интернет-банке клиент подтверждает с помощью СМС-кода                                                            |                                                                                                                |
| F8     | Ставки по депозитам должны быть доступны сотрудникам бэк-офиса кредитов и депозитов                                                           | Возможно, расчет ставки и ее согласование стоит реализовать в АБС                                              |
| F9     | Менеджер бэк-офиса подтверждает в АБС условия по заявке на депозит                                                                            |                                                                                                                |
| F10    | Клиент получает СМС-уведомление после подтверждения размера ставки и открытия депозита                                                        |                                                                                                                |
| **U**  | **Удобство использования (Usability)**                                                                                                        |                                                                                                                |
| U1     | Нужно придерживаться системы дизайна для приложений, которая принята в компании                                                               |                                                                                                                |
| **R**  | **Надёжность (Reliability)**                                                                                                                  |                                                                                                                |
| R1     | Все сервисы (АБС, интернет-банк) должны работать 24/7, SLA 99,9                                                                               |                                                                                                                |
| R2     | Предусмотреть равномерное горизонтальное масштабирование                                                                                      |                                                                                                                |
| **P**  | **Производительность (Performance)**                                                                                                          |                                                                                                                |
| P1     | Отклик по всем операциям в интернет-банке должен быть максимально быстрым и занимать миллисекунды                                             | Сейчас есть проблема: при проведении платежей некоторые справочные данные загружаются больше секунды           |
| **S**  | **Поддерживаемость (Supportability)**                                                                                                         |                                                                                                                |
| S1     | Поддержка интеграционного тестирования                                                                                                        |                                                                                                                |
| **+R** | **+ Ограничения (Restrictions)**                                                                                                              |                                                                                                                |
| R1     | Данные, передаваемые с сайта, должны быть защищены шифрованием трафика                                                                        |                                                                                                                |
| R2     | Работу с СМС желательно реализовать силами команды разработки банка, без привлечения подрядчика                                               |                                                                                                                |
| R3     | В интернет-банке данные при передаче надо защитить механизмом шифрования                                                                      |                                                                                                                |
| R4     | Используем технологии, которые уже есть в банке:<br>СУБД: MS SQL, Oracle<br>Веб-фреймворк: ASP.NET<br>Бэкенд: PHP, Java<br>Фронтенд: React.js |                                                                                                                |
| R5     | Новые технологии должны быть совместимы с существующими платформами разработки                                                                |                                                                                                                |
| R6     | Очереди сообщений - Kafka                                                                                                                     | На перспективу. Надо учитывать, что текущая версия платформы интернет-банка с ней несовместима                 |
| R7     | В рамках задачи открытия депозитов надо подумать о переводе интернет-банка на микросервисную архитектуру                                      |                                                                                                                |
| R8     | Избежать прямой работы интернет-банка с API АБС                                                                                               | Команда АБС утверждает, что база данных системы уже перегружена                                                |
